# HR Analytics - Employee Attrition Dashboard

A Streamlit based interactive dashboard to analyze employee attrition and predict whether an employee will leave the company.

Created by: BINDU

# Features
1.  Direct Data Loading: No need to upload file every time, auto-loads CSV.
2.  Data Preview: Shows first 5 rows of the dataset.
3.  8 Visualizations :
    - Attrition Count (Pie Chart)
    - Department vs Attrition
    - Age Distribution
    - OverTime vs Attrition
    - Monthly Income Distribution
    - Job Satisfaction Count
    - Gender vs Attrition
    - Years At Company vs Monthly Income (Scatter Plot)
4.  Prediction Model : Random Forest Classifier to predict attrition with accuracy score.

# Tech Stack
- Python
- Streamlit
- Pandas, Matplotlib
- Scikit-learn
